# CodaPact identity

**CodaPact** joins a musical coda, code, a contract, and the idea of impact.
The tagline is **Contracts into callable tools.**

The original mark takes the coda's circle and axes and opens the ring into two
balanced boundaries. It suggests a shared contract between interchangeable
implementations. The amber center marks the point where a definition becomes
an executable call. The identity uses a single symbol, without a collage of
music notes, terminal windows, and paperwork.

| Role | Color |
| --- | --- |
| Wordmark and axes | Navy `#18283e` |
| Open ring | Teal `#15a99b` |
| Execution point | Amber `#d99732` |
| Supporting text | Slate `#52627a` |

Use [the wordmark](wordmark.svg) on light backgrounds and
[the standalone mark](mark.svg) where space is limited. SVGs use
system fonts and contain no scripts, external resources, or embedded images.

Mike selected the name on 2026-10-29. Preliminary exact-name repository and
registry searches found no obvious collisions. This is not a reservation or
legal clearance; recheck before publication.
