# Guides

Use a local example before supplying a production contract. Generation does not
contact an API server; generated commands make requests only when called.

- [Getting started](getting-started.md): install, generate, and make a loopback call.
- [Endpoint selection](endpoint-selection.md): preview and generate a selected surface.

Consult [configuration](../reference/configuration.md) for exact precedence and
[supported features](../reference/supported-features.md) before generating real clients.
