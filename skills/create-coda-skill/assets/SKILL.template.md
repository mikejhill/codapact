# {{API_NAME}}

`{{PROGRAM}}` is a command-line client for the {{API_NAME}} API, generated by Codapact and
published on PyPI as `{{DISTRIBUTION}}`. The CLI documents itself. This skill only gets it
ready; take every usage detail from the CLI, which always matches the installed version.

## Once per skill load

1. Install or update it: `uv tool install --upgrade {{DISTRIBUTION}}`. Then call
   `{{PROGRAM}}` directly. Without uv: `pipx install {{DISTRIBUTION}}` then
   `pipx upgrade {{DISTRIBUTION}}`, or `python -m pip install --upgrade {{DISTRIBUTION}}`.
   If `{{PROGRAM}}` is still not on PATH, prefix every call with `uvx --from {{DISTRIBUTION}}`.
2. Run `{{PROGRAM}} describe --brief` and read its `start`, `auth`, `exit_codes`, and `notes`.
   They explain readiness, credentials, and how to find commands.
3. Follow `start`: it begins with `{{PROGRAM}} doctor`, whose exit code says whether the CLI
   is ready and what to fix.

Do not repeat these steps for every command in the same session.

## For each task

- Find the command in the `describe --brief` list, then run `{{PROGRAM}} describe COMMAND`
  for its arguments and output schema before you first use it.
- On a non-zero exit, read the error and its hint, and look the code up in `exit_codes`.

## Rules

- Before a command without the `read_only` trait, confirm with the user unless they asked
  for exactly that change. Use `--dry-run` to show what it would send.
- Credentials come from the user. Never ask them to paste a secret into the chat; give them
  the `auth` login command from `describe` to run in their own terminal.
